# BandSprint

An all-in-one, interactive web dashboard providing AI-driven IELTS exam preparation, multi-accent neural speech practice, diagnostics, speaking turn evaluations, and IELTS band-descriptor-calibrated scoring tools.

## Features
- **Multi-Accent Neural Speech**: 16 voice characters across British RP, Australian, American, Canadian, New Zealand, and Irish accent styles using neural audio.
- **AI Speaking & Writing Evaluator**: Real-time diagnostic assessment powered by Gemini 3.5 Flash-Lite using IELTS band-descriptor-aligned criteria.
- **Full-Stack Architecture**: Express backend with streaming audio endpoints, secure session authentication, and Stripe webhook integration.

## Getting Started
```bash
# Install dependencies
npm install

# Start local development server (runs full-stack Express + Vite on port 3000)
npm run dev
```
